# Soybean

Soybean 简易选品工具, 该工具是用python的标准库 Tkinter GUI工具包制作而成.


工具前期集成:
1. 淘宝
2. 1688
3. 天猫
4. vvic
5. 杭州女装

等平台的选品, 支持店铺搜索,查看售价,导出数据等功能.
